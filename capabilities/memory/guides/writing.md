# Writing memory entries

How to decide what belongs in memory, and how to write an entry that is still useful when a later session reads only its title.

## What an entry is

An entry is one conclusion that should govern work not yet done and has no other home yet. An account of what a run did belongs in that run's own record, a procedure belongs in a routine, and a settled rule belongs in the project's doctrine. Memory holds the conclusion until it has one of those homes, and the drop that retires it names where it went.

## The title carries the conclusion

Most sessions see an entry as one index line, so the title states the conclusion itself rather than its topic: "Bare dates are read as UTC" serves a reader who never opens the entry, "Notes on dates" does not. The text then gives the reason, the evidence it rests on and where that evidence lives, in a few sentences.

## Decisions are pinned and quoted

When the owner of the project decides something, record it as an entry, quote their words exactly as they said them inside quotation marks, and pin it. A pinned entry stays in every session's block whatever its age, and no grooming pass merges or drops it; a pass that would lose a quotation is refused, so quoting is what keeps the words intact.

## Changing your mind

An entry's text never changes. When a conclusion changes, supersede the old entry with a new one that states the conclusion as it now stands, and give the reason; the old entry stays readable in its trail. When a conclusion simply stops holding, drop it with the reason, and when it was promoted into doctrine, a routine or a task, name that destination so a reader can follow it.

## A secret written by mistake

A secret never belongs in memory. If one lands there, drop the entry with its whole id and the purge option: it is the one deletion the store allows, and it leaves the trail without the text. Then rotate the secret, since it was readable while it stood.

## Reading back

The block in context is a summary of the newest entries; search is how the rest is reached, and showing an entry gives its whole text and trail. When answering a question would take more than one lookup, hand the search to a subagent that returns only its conclusion, so the reading does not crowd the session. `memory help` states every verb and option.
